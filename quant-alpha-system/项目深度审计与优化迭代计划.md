## 二、预测模型深度审计

### 2.1 当前"预测"的真相

**关键发现**：`run_analysis.py` 第 59-145 行的 `predict_step` **并没有使用任何机器学习模型**。  

它所做的事情是：
```python
# 实际上只是一段手写的均线判断规则
momentum = (close[-1] / close[-20]) - 1
base_prob = 50.0 + (momentum * 200)  # 用动量线性映射到概率
```

这是一个**纯规则引擎**，跟 LSTM、XGBoost 没有任何关系。它存在以下致命缺陷：

| 缺陷 | 说明 |
|------|------|
| **误导性** | 输出"上涨概率 65%"之类的数字，给用户一种 AI 预测的错觉，实际上只是 `50 + 动量×200` 的线性公式 |
| **无衰减建模** | 使用 `0.85^i` 的固定指数衰减来模拟"越远越不确定"，这是假设，不是预测 |
| **胜率是伪造的** | `win_rate = base_prob * 1.05`，胜率直接从概率转换来，不是通过历史验证得出 |
| **无训练过程** | LSTM 和 XGBoost 的 `.train()` 从未被任何脚本调用 |

### 2.2 LSTM 预测器代码审计

`modules/predictors/lstm_predictor.py` 本身的代码质量是可以的，但存在以下问题：

| 编号 | 问题 | 说明 |
|------|------|------|
| P-1 | **全量数据训练，无 Train/Val/Test 拆分** | `train()` 方法直接在全部数据上训练，无法评估泛化能力 |
| P-2 | **无 Early Stopping** | 固定 100 个 epoch，容易过拟合或浪费计算 |
| P-3 | **无特征标准化** | 原始价格/成交量直接喂入 LSTM，量纲差异巨大会导致梯度爆炸 |
| P-4 | **输出维度设计不合理** | `output_dim=3`（概率、趋势、目标价）用同一个线性层输出，但这三者的尺度和含义完全不同 |
| P-5 | **无滑动窗口数据准备** | 缺少 `create_sequences()` 等时间窗口切片函数，LSTM 需要 `(batch, seq_len, features)` 格式 |

### 2.3 XGBoost 选股器审计

`modules/selectors/xgboost_selector.py` 代码实现合理，但：

| 编号 | 问题 |
|------|------|
| X-1 | 没有任何标签（Label）生成逻辑。XGBoost 是监督学习，需要标注"未来 N 日是否上涨"作为 y，但整个项目中没有这个步骤 |
| X-2 | 没有时序交叉验证（Walk-Forward Validation），如果直接 train/test 会引入未来信息 |
| X-3 | 未被任何脚本调用 |

## 四、回测框架审计

### 4.1 Backtrader 引擎（`modules/backtest/bt_engine.py`）

| 编号 | 问题 | 严重级别 |
|------|------|---------|
| B-1 | **策略过于简单**：只看 score > 0.6 就买，没有结合趋势过滤、大盘环境、板块共振 | 🟡 |
| B-2 | **仓位管理原始**：固定 20% 仓位，没有 Kelly 公式或风险平价逻辑 | 🟡 |
| B-3 | **止盈止损僵化**：10% 止盈 / 5% 止损是写死的，没有基于 ATR 的动态止损 | 🟡 |
| B-4 | **缺少净值曲线输出**：`BTEngine` 没有返回每日净值序列，HTML 报告的"图表分析"区域是空的 | 🔴 |
| B-5 | **年化收益率计算错误**：使用 `total_return / years` 的简单除法，应使用 `(1 + total_return) ^ (1/years) - 1` 复合年化 | 🟡 |
| B-6 | **只支持单股回测**：`run_backtest.py` 硬编码了 `600584.SH`，无法对策略进行多股或组合级别的回测 | 🔴 |
| B-7 | **旧回测引擎未清理**：`backtest/engine.py` 与 `modules/backtest/bt_engine.py` 并存，职责重叠 | 🟡 |

### 4.2 回测数据的反直觉

当前回测结果（52.7% 胜率 / 8.83% 总收益 / -0.09 夏普）的核心原因是 **CompositeSelector 被错误地应用在了时间序列上**。它本来是设计用于截面选股的（同一时刻对比不同股票），但在回测中被迫对单只股票的历史时间序列做 rank 打分，这在统计上不具备预测意义。

## 五、从大作手视角看策略问题

作为一名实战派 A 股大作手，我认为当前策略存在以下根本性缺陷：

### 5.1 忽视市场环境（大盘择时）

> 在 A 股，**"大盘跌，个股不生"** 是铁律。

当前系统完全没有大盘择时模块。当沪指处于 250 日均线下方时，即使个股评分再高，买入也大概率亏钱。**应加入大盘过滤器**。

### 5.2 忽视板块联动（热点轮动）

> 涨停板的 80% 来自板块效应，而非个股基本面。

系统虽有板块选股功能（`run_sector_scan.py`），但选股后没有进一步分析板块的动量（板块是否正在走强），也没有做板块轮动策略。

### 5.3 忽视量价结构

> "量在价先"——放量突破和缩量回调是 A 股最核心的交易信号。

当前因子中只有一个 `volume_ratio`（量比），缺少以下关键量价因子：
- 地量信号（成交额连续萎缩至 N 日最低）
- 突破均量线的放量确认
- OBV（能量潮指标）

### 5.4 缺少风控体系

> "会买的是徒弟，会卖的才是师傅。"

当前的止盈止损是写死的百分比，没有：
- 基于 ATR 的动态止损（波动率自适应）
- 保本止损（浮盈后移动止损线到成本价上方）
- 市场系统性风险的强制减仓机制

### Phase 3：打通真实双轨预测（3-4 周）

> **目标**：让 LSTM 和 XGBoost 同时工作并融合

#### 3.1 XGBoost 截面选股器（改造）

```
流程：
1. 遍历全市场 → 计算因子截面 → 标注未来 5 日涨跌 (y)
2. Walk-Forward 训练：以滚动窗口避免未来函数
3. 预测当日截面中每只股票的上涨概率
4. 取 Top 20 构建等权组合
```

#### 3.2 LSTM 时序预测器（改造）

```
流程：
1. 对选中的个股，切出 (seq_len=30, features=N) 的滑动窗口
2. 标签：未来 5 日累计收益率（回归任务）
3. 按时间拆分 Train(60%) / Val(20%) / Test(20%)
4. 加入 EarlyStopping + ReduceLROnPlateau
5. 输出：目标价、上涨概率（通过 Sigmoid 层）
```

#### 3.3 集成融合

```python
final_score = 0.5 * xgb_prob + 0.3 * lstm_prob + 0.2 * composite_score
```

| **因子体系** | **4.0** | 数量不足、有效因子偏少，缺少 A 股核心的动量和量价因子 |

### 最终判断

> 这个项目的**骨架和架构是优秀的**，具备了成为一个真正能赚钱的量化系统的所有脚手架。但当前它的"肌肉"（预测模型）和"神经系统"（因子信号）还远远不够：模型是假的，因子太少，回测太简陋。
>
> **只要按照上述 Phase 1-3 的路线图逐步填充，这套系统完全有潜力成为一个年化 15-30% 的私人量化交易平台。**
